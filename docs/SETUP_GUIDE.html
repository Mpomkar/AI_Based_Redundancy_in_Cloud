2. Get the project

git clone https://github.com/Mpomkar/AI_Based_Redundancy_in_Cloud.git
cd AI_Based_Redundancy_in_Cloud

Or download the ZIP from GitHub and extract it.

3. One-time setup (automated)

Run once per machine after cloning.

Windows

.\scripts\setup.ps1

Or double-click scripts\setup.bat or scripts\start-all.bat (setup + start servers).

macOS / Linux

chmod +x scripts/*.sh
./scripts/setup.sh

The setup script:

  • Verifies Python and Node.js versions
  • Creates backend\.venv and installs Python packages
  • Runs npm install in frontend\
  • Verifies backend imports

Time: about 2–5 minutes on first run.

4. One-time setup (manual)

Backend

cd backend
python -m venv .venv

# Windows
.\.venv\Scripts\Activate.ps1
pip install -r ..\requirements.txt

# macOS/Linux
source .venv/bin/activate
pip install -r ../requirements.txt

python -c "from app.main import app; print('OK')"

Frontend

cd frontend
npm install

On Windows PowerShell, use npm.cmd install if scripts are blocked.

5. Running the application

Windows (both servers)
.\scripts\start-all.ps1
Backend only
.\scripts\start-backend.ps1
Frontend only
.\scripts\start-frontend.ps1
macOS/Linux
./scripts/start-backend.sh
./scripts/start-frontend.sh

Manual commands

Backend (from backend, venv active):

python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

Frontend (from frontend):

npm run dev

Open http://localhost:5173 in your browser (use the port shown in the terminal if different).

9. Troubleshooting

npm — “running scripts is disabled” (Windows)

Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process
# Or use setup scripts / npm.cmd

vite not recognized / 500 on upload

  • Run .\scripts\setup.ps1 (installs dependencies).
  • Start backend: .\scripts\start-backend.ps1.

Could not read package.json

Run npm from frontend\, not project root.

Port 5173 in use

Vite uses the next free port (e.g. 5174). Use the URL in the terminal.

Dashboard “Error” banner

Backend is not running. Start it and refresh the page.
